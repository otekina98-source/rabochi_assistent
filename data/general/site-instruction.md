\# Инструкция по работе с сайтом "Рабочий Ассистент"



\## 📌 Что это за сайт?



\*\*Рабочий Ассистент\*\* — это единая платформа для сбора всех сверок и инструкций по работе с маркетплейсами (ЯндексМаркет, ОЗОН, Wildberries). 



\*\*Цель:\*\* собрать все необходимые инструменты в одном месте для удобной и быстрой работы.



\---



\## ⚠️ ВАЖНО!



\*\*Если в инструкции к сверке НЕ написано, что нужно переводить PDF файл в Excel или какой-то другой формат, то мы этого НЕ ДЕЛАЕМ!\*\*



Загружайте файлы в том формате, в котором они указаны в инструкции (PDF остаётся PDF, Excel остаётся Excel).



\---

\### 📖 Инструкция

\###  ЯндексМаркет

Все сверки по ЯндексМаркет:



\#### 1. \*\*\[Сверка ШК и реестр](../data/yandex-market/shk-reestr/index.html)\*\*

\*\*Что делает:\*\* Сравнивает штрихкоды из PDF с наклейками с реестром номеров из 1С



\*\*Как использовать:\*\*

\- Загрузите PDF файл с наклейками в левое поле

\- Вставьте номера заказов в правое поле (каждый с новой строки) или загрузите файл

\- Нажмите "НАЧАТЬ СВЕРКУ"

\- Дождитесь окончания обработки

\- Внизу появится таблица с результатами



\*\*Результат:\*\* Показывает расхождения — какие номера есть только в наклейках, какие только в реестре



\---



\#### 2. \*\*\[Сверка АКТ и реестр](../data/yandex-market/akt-reestr/index.html)\*\*

\*\*Что делает:\*\* Сравнивает номера из акта (PDF) с реестром номеров из 1С



\*\*Как использовать:\*\*

\- Загрузите PDF с АКТом в левое поле

\- Вставьте номера заказов из 1С в правое поле

\- Нажмите "НАЧАТЬ СВЕРКУ"

\- Дождитесь обработки

\- Смотрите результаты ниже



\*\*Результат:\*\* Показывает расхождения между актом и реестром



\---



\#### 3. \*\*\[Сверка по грузоместам](../data/yandex-market/gruzomesta/index.html)\*\*

\*\*Что делает:\*\* Сравнивает количество грузомест из Excel файла ЛК с реестром из 1С



\*\*Как использовать:\*\*

\- Скачайте Excel файл "список заказов" из ЛК

\- Удалите все столбцы кроме \*\*Номер заказа\*\* и \*\*Грузоместа\*\*

\- Скопируйте и вставьте в левое поле

\- Вставьте номера из 1С вместе с грузоместами (удалите лишние столбцы) в правое поле

\- Нажмите "НАЧАТЬ СВЕРКУ"

\- Дождитесь обработки

\- Смотрите результаты ниже



\*\*Результат:\*\* Показывает расхождения по количеству грузомест



\---



\### 🏪 ОЗОН

Все сверки по ОЗОН:



\#### 1. \*\*\[Сверка Лист отгрузки и реестр](../data/ozon/list-reestr/index.html)\*\*

\*\*Что делает:\*\* Сравнивает номера отгрузок из листа отгрузки (PDF) с номерами из 1С



\*\*Как использовать:\*\*

\- Сформируйте отгрузку в ЛК

\- Скачайте \*\*Лист отгрузки\*\*

\- Вставьте его в левое поле

\- Вставьте номера заказов из 1С из столбика "Телефон1" в правое поле

\- Нажмите "НАЧАТЬ СВЕРКУ"

\- Дождитесь обработки

\- Смотрите результаты ниже



\*\*Результат:\*\* Показывает расхождения между листом отгрузки и 1С



\---



\#### 2. \*\*\[Сверка Лист подбора и реестр](../data/ozon/podbor-reestr/index.html)\*\*

\*\*Что делает:\*\* Сравнивает номера из листа подбора (PDF) с реестром



\*\*Как использовать:\*\*

\- Загрузите Лист подбора (PDF)

\- Загрузите реестр номеров

\- Нажмите "НАЧАТЬ СВЕРКУ"

\- Дождитесь обработки

\- Смотрите результаты



\*\*Результат:\*\* Показывает расхождения между листом подбора и реестром



\---



\#### 3. \*\*\[Сформировать ЛП и ШК по порядку](../data/ozon/lp-sk/index.html)\*\*

\*\*Что делает:\*\* Создаёт новый лист подбора и наклейки, отсортированные по алфавиту



\*\*Как использовать:\*\*

\- Загрузите \*\*Лист подбора\*\* (PDF)

\- Загрузите \*\*ШК\*\* (PDF с наклейками)

\- Загрузите \*\*Прайс\*\* (Excel)

\- Нажмите "СФОРМИРОВАТЬ"

\- Смотрите результат внизу и скачайте файлы



\*\*Результат:\*\* 

\- Новый ЛП в Excel (товары по алфавиту)

\- Новые наклейки в PDF в том же порядке

\### 🏪 Wildberries

Все инструменты по Wildberries:



\#### 1. \*\*\[Курьеры экспресс](../data/wildberries/couriers/index.html)\*\*

\*\*Что делает:\*\* Формирует файлы для назначения курьеров на основе Excel файла



\*\*Как использовать:\*\*

\- Загрузите Excel файл с данными курьеров

\- Выберите нужные даты доставки

\- Проверьте статус (по умолчанию "Ожидает курьера")

\- Выберите склады (галочками): МБТ, СГТ, СПБ

\- Нажмите "СФОРМИРОВАТЬ ФАЙЛЫ"

\- Скачаются 2 Word файла: с наименованиями и без



\*\*Результат:\*\* 

\- 2 Word файла с разделением по курьерам и складам

\- В одном файле — с наименованиями товаров

\- В другом — только номера заказов (стикеры)
